# Legal Disclaimer & Project Notice

**Project status:** pz-character is an independent, fan-made tool that extracts character models, animations, and appearance data out of a *Project Zomboid* install for viewing/use in Blender. It is not affiliated with, endorsed by, or sponsored by The Indie Stone.

## What this project is
- An original codebase (Python extractor + Blender add-on) written independently, based on the author's own reverse-engineering of the *Project Zomboid* Build 42 character file formats (`.x` models, animations, appearance data) purely for interoperability — reading a format to display its content, not reimplementing the game.
- File-format knowledge (how data is laid out on disk) is not, by itself, protected by copyright — copyright protects specific *expression*, not facts or interoperability information. This project aims to implement its own expression of an extractor/viewer for that format.

## What this project is NOT
- This repository contains **no code, binaries, or assets owned by The Indie Stone**. No source files from *Project Zomboid* have been copied, decompiled, or included.
- This repository contains **no copyrighted sprites, textures, audio, models, or other original game assets**.
- This project does not include, distribute, or facilitate piracy of *Project Zomboid* in any form.

## Requirement to own the base game
To use this tool, **you must own a legitimate copy of Project Zomboid via Steam (or another authorized storefront)**. This tool does not provide, unlock, or generate any official game assets — it reads assets from your own legally-obtained installation, similar to how a mod tool operates. Nothing extracted is bundled with or distributed by this repository.
